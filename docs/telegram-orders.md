# RESET Clinic Shop — Telegram сповіщення про замовлення

## Що надсилається
- Нове замовлення Monobank після створення рахунку (платіж **ще не підтверджений**).
- Нове замовлення з оплатою готівкою при самовивозі.
- Підтвердження онлайн-оплати тільки після **підписаного** webhook Monobank.
- Зміни статусів: готівку прийнято, скасовано, повернено кошти, передано в роботу, відправлено, виконано.

У повідомленні: номер замовлення, клієнт і контакти, спосіб та адреса доставки,
спосіб і поточний статус оплати, склад кошика, кількість, сума, коментар і посилання
на адмінпанель. Не використовуйте публічну групу для персональних даних покупців.

## Обов'язкові налаштування Cloudflare
1. Створити бота в Telegram через @BotFather і додати його до **приватної**
   робочої групи. Надати право писати повідомлення.
2. Отримати числовий ID групи (-100...). Не переплутати з ID особистого чату.
3. Cloudflare Dashboard → Workers & Pages → reset-clinic-shop →
   Settings → Variables and Secrets:
   - `TELEGRAM_BOT_TOKEN` — Secret, токен Telegram бота;
   - `TELEGRAM_CHAT_ID` — Secret, числовий ID потрібної приватної групи;
   - `TELEGRAM_THREAD_ID` — необов'язково, ID теми групи (для форумів).
4. Зберегти секрети та переконатися, що вони застосовані у Production.
   Не записуйте значення в репозиторій, документацію чи листування.
5. Зайти в /admin/orders і натиснути **Надіслати невідправлені в Telegram**
   після налаштування. Лише раніше збережені в черзі події надсилаються —
   старі історичні замовлення не розсилаються автоматично.

## Надійність
Замовлення спочатку записується в D1, після чого в окрему D1-таблицю
`shop_order_telegram_notifications` записується подія; кожна подія має унікальний ключ.
Якщо Telegram недоступний або токени не задано, повідомлення залишається
у черзі. Система пробує його надіслати при наступних замовленнях;
адміністратор може примусово повторити з розділу замовлень.
Стан: GET /api/admin/telegram/orders
Повторити до 20 подій: POST /api/admin/telegram/orders
Обидва маршрути вимагають чинної адмін-сесії.

Черга не впливає на статус оплати. Кошти визнаються отриманими **лише**
після підписаного webhook Monobank або ручного підтвердження готівки.
Наявні повідомлення можуть бути повторені у винятковому випадку, якщо
Telegram отримав їх, а підтвердження запису в D1 не завершилося.

**Важливо:** без конфігурації Telegram у Cloudflare інтеграція працює лише
як черга в D1; повідомлення в групу фактично не надходитимуть.
