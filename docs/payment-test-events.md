# RESET Clinic Shop — публічна тестова оплата

**Публічна адреса:** https://shop.resetclinic.org/admin/payment-test

Тестувальникам **не потрібен вхід до адмінпанелі**. Водночас сторінка
не надає доступу до інших адміністративних маршрутів та захищених API.

## Як працює
Відвідувач вказує умовну суму й спосіб оплати, натискає кнопку запуску —
і сервер моделює `InitiateCheckout`, `AddPaymentInfo` та `Purchase`.
Ці події відправляються лише через Meta Conversions API із обов'язковим
серверним `test_event_code`, ніколи як реальні покупки.

Тестова сторінка не надсилає фактичних платіжних запитів до Monobank,
не змінює замовлень або залишків у D1, не відправляє повідомлень Telegram,
не записує реальних транзакцій і не збирає даних платіжних карток.

Якщо аналітика не налаштована, доступна локальна симуляція, яка явно
вказує, що зовнішні події **не були відправлені**.

## Як налаштувати
У Cloudflare Worker `reset-clinic-shop`, Settings → Variables and Secrets:
- `META_PIXEL_ID` — ID Meta Dataset/Pixel;
- `META_CAPI_ACCESS_TOKEN` — **Secret**, токен Conversions API;
- `META_TEST_EVENT_CODE` — **Secret**, поточний код Test Events із Meta Events Manager.

Публічний відвідувач **не може вводити або міняти** токени чи TEST-код.
Значення не записуються в GitHub і не передаються браузеру.
Код отримати через Meta Events Manager → Pixel/Dataset → Test Events.

## Захист публічного API
- POST тільки з того самого Origin.
- Ізольований маршрут `/api/payment-test` (старий адміністративний
  `/api/admin/payment-test` видалено).
- Валідація суми та способу оплати; синтетичний `event_id`.
- Лише серверний TEST-код дозволяє виклик Meta; без коду — локальна симуляція.
- D1-ліміти на виклики зовнішньої Meta API:
  максимум **3 запуски на годину з однієї IP-адреси** й
  **60 запусків на добу загалом**.
- Якщо D1 недоступна, зовнішнє відправлення блокується.
- IP не зберігаються в D1 відкритим текстом (хеш із серверним секретом).
- Страница має `noindex`, але **доступна за прямим посиланням**.

## Перевірка
Відкрити адресу в інкогніто, вибрати суму, натиснути запуск, переглянути
журнал подій. Статус «Meta прийняла» означає API-підтвердження,
а не реальну оплату чи підтверджене відображення у звітах.
